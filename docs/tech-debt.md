# Технический долг

Дневник отложенных решений. Записи не удаляем: закрытая получает пометку
«сделано» с датой и коммитом, чтобы было видно, откуда она взялась и чем
закрылась. Одна запись — одно решение, которое можно сделать за отдельный заход.

Правило пополнения: всё, что сознательно отложено в ревью, спеке или
разговоре, попадает сюда в тот же день. Запись без «почему отложено» и без
влияния бесполезна — не заводим.
